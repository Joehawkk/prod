# T-Match — приложение для знакомств

Фронтенд веб-приложения для знакомств, разработанный на тестовой базе данных пользователей Т-Банка в рамках Международной олимпиады по промышленной разработке PROD.

## Кейс

Обычные дейтинг-приложения подбирают людей по анкете — это даёт много случайных совпадений. Т-Банк знает, как люди тратят деньги и проводят время, и использует эти данные чтобы находить по-настоящему похожих людей.
Свайпай анкеты, общайся с теми, кто ответил взаимностью, и назначай встречи прямо в чате.

## Функции

- **Лента** — свайп-карточки с AI-объяснением совместимости и тегами
- **Лайки** — все, кто лайкнул тебя
- **Матчи** — список взаимных симпатий
- **Чат** — реальный времени через WebSocket, поддержка приглашений на встречу
- **Профиль** — редактирование анкеты, фото, город, описание
- **Онбординг** — заполнение профиля при первом входе

## Стек

### Frontend

- React 19 + TypeScript + Vite
- Tailwind CSS v4
- Framer Motion — анимации
- Tanstack React Query — серверное состояние
- Zustand — клиентское состояние
- React Hook Form + Zod — формы и валидация
- WebSocket — чат в реальном времени

### Тесты

- Vitest + Testing Library

### CI/CD

- GitLab CI — сборка, тесты, деплой

## Запуск

### Требования

- Node.js 20+

### Установка

```bash
git clone https://github.com/Joehawkk/prod.git
cd prod
npm install --legacy-peer-deps
npm run dev
```

Приложение: `http://localhost:5173`

### Тесты

```bash
npm run test
```
